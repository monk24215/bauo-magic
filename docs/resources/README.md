# Research resources

Background research on evaluating AI and technology for positive, creator-aligned evolution. These files are reference material only; nothing in the build reads them.

| File | Format | Topic |
|---|---|---|
| `AI Evaluation Framework for Positive Evolutionary Technology.smmx` | SimpleMind map | Full evaluation framework (most complete version) |
| `AI Evaluation Framework for Positive Evolutionary Technology.opml` | OPML outline | Outline export of the framework |
| `AI Framework for Positive Evolutionary Technology.smmx` | SimpleMind map | Earlier, shorter draft of the framework |
| `AI Creator-Aligned Characteristics for Meaningful Technological Evolution.smmx` / `.opml` | Map + outline | Creator-aligned characteristics |
| `AI Evaluating the Positive.smmx` | SimpleMind map | Evaluating positive outcomes |
| `Positive Evolution of Artificial Intelligence.opml` | OPML outline | Positive evolution of AI |
| `AI-Centric Evaluation of Healthy AI Evolution.txt` | Plain text | Narrative write-up |
| `Concerns About Tech Proliferation.smmx` | SimpleMind map | Risks of technology proliferation |
| `Top 10 High-Risk.smmx` | SimpleMind map | Top 10 high-risk areas |

`.smmx` files open in [SimpleMind](https://simplemind.eu/). `.opml` files open in most outliners and mind-map tools.
